# 🤖 Bot de WhatsApp com IA — n8n + WAHA

Este é um mini projeto focado na criação de um bot de Inteligência Artificial automatizado para responder mensagens recebidas diretamente no WhatsApp.

## 🚀 Sobre o Projeto
O objetivo principal é estruturar um ecossistema auto-hospedado (self-hosted) capaz de receber mensagens de usuários, processá-las utilizando uma Inteligência Artificial e devolver respostas de forma humanizada e automatizada.

### 🛠️ Tecnologias Utilizadas
* **[n8n](https://n8n.io)**: Plataforma de automação baseada em fluxos de trabalho (workflow) utilizada para orquestrar as mensagens e integrar as ferramentas.
* **[WAHA (WhatsApp HTTP API)](https://waha.devlike.pro)**: Uma API de código aberto que funciona como gateway do WhatsApp Web, permitindo enviar e receber mensagens via requisições HTTP REST comuns.
* **OpenAI Chat Model**: Modelo de Inteligência Artificial utilizado para gerar as respostas inteligentes e personalizadas do chatbot.
* **OpenRouter**: Ferramenta gratuita para gerar Api Key usada no OpenAI.
